FAQ

Does this send data anywhere? ▾

TRACIDUS keeps the message-analysis logic in your browser. When a URL is present, that extracted URL is sent to the TRACIDUS backend for technical intelligence, which securely queries VirusTotal. Your VirusTotal API key is never exposed to the browser.

Can I export results? ▾

Yes. You can download the radar chart as a PNG, export a full JSON report of the analysis, or simply copy a summary to your clipboard.

How is link reputation determined? ▾

TRACIDUS first applies its local URL heuristics and optional local AI. When a URL is available, the frontend also requests technical intelligence from the TRACIDUS backend, which checks VirusTotal and returns normalized evidence such as vendor detections, reputation, title, and related metadata.
